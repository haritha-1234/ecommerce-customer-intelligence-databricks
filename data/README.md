# Dataset

This project uses the **Indian E-Commerce Customer Behavior & Purchase** dataset from Kaggle.

The original dataset contains 25,000 e-commerce session records and 29 columns.

The dataset is not included in this repository.

To reproduce the project:

1. Download the dataset from Kaggle.
2. Save the CSV as `Ecommerce.csv`.
3. Place it in this `data/` directory for local development.
4. Upload the CSV to a Databricks Volume when running the notebook in Databricks.

The dataset source is:

Kaggle — Indian E-Commerce Customer Behavior & Purchase
https://www.kaggle.com/datasets/kundanbedmutha/indian-e-commerce-customer-behavior-and-purchase/data
