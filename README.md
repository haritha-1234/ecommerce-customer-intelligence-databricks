# E-Commerce Customer Intelligence with PySpark, Databricks & GenAI

## Overview

This project explores an e-commerce customer behavior dataset using
PySpark, Databricks, Machine Learning, MLflow, embeddings, and Large
Language Models (LLMs).

The goal is to understand customer behavior, predict purchase intent,
and experiment with a simple GenAI-based customer review assistant.

## Project Goals

- Learn and apply PySpark for large-scale data processing
- Perform customer and product behavior analysis
- Build a purchase prediction model using Spark ML
- Track ML experiments using MLflow
- Work with Delta tables in Databricks
- Explore embeddings and semantic search
- Build a simple LLM-based review analysis assistant
